# Bundled Dependency Licenses

This folder contains license texts for the main third-party components that may be bundled with distributed builds of IR Explorer.

Included files:

- `PYTHON.txt` - Python Software Foundation license text
- `TCL_TK.txt` - Tcl/Tk license terms
- `NUMPY.txt` - NumPy license text
- `PYYAML.txt` - PyYAML license text
- `PYMUPDF.txt` - PyMuPDF license/reference file from the installed package

Notes:

- PyInstaller is documented in `THIRD_PARTY_NOTICES.md`, but is not included here because it is a build tool rather than a bundled runtime dependency.
- PyMuPDF requires separate attention because its package metadata indicates AGPL v3 or commercial licensing.
